# Driver Drowsiness Detection

هذا المشروع يكتشف نعاس السائق باستخدام الذكاء الاصطناعي وكاميرا الويب.

## معلومات الطالب
- الاسم: محمد احمد سلطان الشيباني
- المجموعة: 1
- الشعبة: (ب)

## طريقة التشغيل
1. تأكد من تثبيت جميع المتطلبات (انظر الكود).
2. ضع ملف صوت باسم `alert.wav` في نفس المجلد.
3. شغّل الكود:
   ```
   python driver_drowsiness_detection.py
   ```

بالتوفيق!
